# Aviation Market Data Exploration and Analysis

## Project Overview

This project examines aviation market data for Canada using exploratory data analysis and statistical methods. The objective was to identify important patterns, relationships, and differences within the market and translate the results into meaningful business insights.

## Project Components

The repository includes:

- Aviation market dataset
- Jupyter Notebook containing the complete analysis
- Final project presentation
- Written project conclusion
- Supporting project files

## Methods

The analysis included:

- Data preparation and inspection
- Descriptive statistics
- Exploratory data analysis
- Data visualization
- Statistical hypothesis testing
- Interpretation of results
- Business-focused conclusions

## Tools

- Python
- Jupyter Notebook
- Pandas
- Statistical analysis
- Data visualization
- Microsoft Excel
- Microsoft PowerPoint

## Files

- `DosSantos530Week12.ipynb` – Complete Python analysis
- `Aviation Market - Canada.xlsx` – Project dataset
- `Term Final Presentation.pptx` – Final presentation
- `Term Project Conclusion Essay.docx` – Written project conclusion

## Key Focus

The project demonstrates how statistical analysis can be used to examine aviation market questions and communicate analytical findings in ways that support business understanding and decision-making.
